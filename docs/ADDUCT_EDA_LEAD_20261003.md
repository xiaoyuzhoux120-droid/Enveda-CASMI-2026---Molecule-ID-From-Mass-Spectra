# 外部EDA线索与当前代码核查

用户提供的招募文字称，作者已按分子划分数据、缓解每分子谱图数量偏斜、检查测试质量/加合物覆盖，并修复约4万行由加合物标准化造成的错误。该数量及修正规则尚未对我们的输入版本验证；此文记录线索，不把对方陈述当作本项目的测量结果。

## 对我们最有价值的内容

1. 按规范分子身份划分：当前冻结V1研究已实现开发/验收身份隔离，unknown排除同身份谱库参考，known删除查询谱与分箱副本。此前已见病例排除范围有历史未完整保留的限制，仍需如实披露。
2. 谱图数量偏斜：旧神经训练使用每分子有限采样；当前研究每身份最多两条查询谱，指标以分子为单位。参考库数量偏斜仍可能造成最大相似度的多次尝试优势，不能声称已经完全解决。
3. 质量/加合物覆盖：查询质量来自 `precursor_mz - ADDUCT_MASS[adduct]`，固定表不含任意电荷解析；不支持标签和错误标签分别可能造成遗漏与错误质量窗。必须核对具体测试加合物和电荷分布，不能凭常见形式推断全部适用。
4. 约4万行加合物错误：`baseline.load_candidates`以分子式质量筛参考，但直接丢弃已提供的 `abs(precursor_error_ppm)>30` 行。因此若该字段由错误标签计算，一部分真实可修复的参考可能被排除。我们尚未定位同样错误、未统计受影响行数、未恢复任何参考行。

## 下一项独立数据实验

先索取来源帖子、数据版本、错误标准化规则与例子；同时可直接对实际训练数据进行只读质量守恒核查。逐行结合分子式/结构精确质量、前体m/z、离子模式、加合物、电荷和来源，比较记录的误差与重新计算的误差。多电荷应使用明确的离子质量与电荷公式，不能简单减单电荷常数。保留原标签、原误差、推定标签、重算误差、置信与修正原因。

仅在唯一且化学合理的修正解释下修复；多解、质量不一致和缺失字段单独保留审计，不自动改成最近标签。按来源和加合物报告：疑似行数、可唯一修复数、恢复参考数、仍不可判定数、每分子数量变化。训练真值用于训练数据质量核查；测试端不得使用未知真值修正，必须另有谱图/元数据依据。

用新冻结数据版本做单项A/B：原数据V1 vs修正数据同一V1，保持目录、规则、路由及排序参数不变。需要新的独立验收协议，或在打开其结果前声明用途；不得在当前已冻结路由研究中临时替换输入。关键结果是候选真值覆盖、分子单位MRR、known保护、受影响病例和耗时，不是修复行数本身。
