## 1. 结论与决策

本轮真实公榜 **MRR@25 = 0.171**，低于历史最佳和化学先验v1的 **0.176**，绝对下降 **0.005**。这次实验没有改善可用的最好方案。下一轮不应以“增加GAN规模或生成数量”为主要目标，应先修正错误保护、候选覆盖和化学证据适用范围，并将研究计算与比赛推理拆开。

同条件对照没有证明GAN提供稳定增益：未知参考任务的路由MRR差为 **+0.000146**，已知参考任务为 **−0.000611**，两组95%配对区间均跨零。GAN确实训练过，但“训练成功”与“识别效果改善”是两件事。

有限图编辑产生了大量合法候选，却没有增加精确真结构覆盖。因此，当前架构尚未证明通用库外结构恢复能力。GAN只生成指纹，结构来自独立的有限图编辑，不是GAN直接解码分子图。

**推荐下一次正式运行：**先完成相同权重的快速推理入口与逐题一致性验证，再进行有新留出集的路由/化学先验对照。GAN保留为研究臂，是否进入下一份提交由运行前冻结的验收标准决定。具体要求见[下一轮PRD](PRD_NEXT_RUN_20261003.md)。

## 4. 当前系统实际做了什么

当前链路为：谱图与元数据 → 谱库相似度及质量过滤 → 外部结构候选 → 神经指纹预测 → 可选有限图编辑 → 化学证据匹配 → 排名融合与保护 → 官方身份去重 → 前25个结构。

| 环节 | 本轮能力 | 主要限制 |
|---|---|---|
| 谱库检索 | 对有相关参考谱的结构检索较强 | 高相似度可能来自错误结构或近邻 |
| 结构目录 | COCONUT及公共目录补充质量匹配候选 | 数据库有结构，不等于质量窗内有结构；扩库也增加竞争 |
| 指纹模型 | 谱图映射2048位Morgan指纹概率 | 指纹不能直接唯一还原结构；BCE不等于排名目标 |
| GAN | 条件G/D交替训练，加入错误结构配对负例 | 指纹增益很小，噪声多样性弱 |
| 图编辑 | 两锚点、单键端点交换、每题最多32个合格图 | 搜索范围局部，合法不等于天然产物合理或精确命中 |
| 化学规则 | 诊断离子/中性丢失匹配，结构SMARTS支持，软加分 | 仅五条规则；模式与加合物限制影响触发 |
| 路由保护 | 高置信保留旧排名；低置信仍固定旧首位 | 会阻止神经模型改正首位及引入扩展池真值 |

公共目录本轮有162,175个原始去重键，其中3,759个带电代表排除于中性质量路径，给COCONUT追加77,572个结构。不是下载了整个PubChem，也不是生成了77,572个新分子。

目前五条项目规则覆盖磷酸胆碱、磷酸乙醇胺、己糖、葡糖醛酸和硫酸酯。MS-FINDER词典适配代码已实现，但其数据许可未经核实，没有将全表发布或完整纳入本次正式输入。已查看的比赛数据页没有证实附带组织方完整诊断词典；不能把项目自建规则称为已全面利用官方词典。

## 5. 同条件GAN实验及实际指标

### 5.1 数据、训练与选入权重

实际拟合59,609个规范身份、115,594张谱；开发991个身份、1,921张谱；未知参考验收994个身份、1,934张谱；已知参考验收是同查询中保留真实参考的880个身份子集。

两臂使用相同初始化、数据顺序、预处理、噪声协议、候选池和图编辑池。每臂训练12个完整epoch、G更新5,424次；GAN额外D更新4,520次。前两轮监督warm-up指标一致。两份实际选入权重均为第6轮：G更新2,712次，GAN D已更新1,808次。

固定配置：保护门槛0.75，神经RRF权重0.35，化学权重0.1；质量窗35 ppm、下限0.006 Da；低置信仍保留历史首位。参数在本轮运行前冻结，没有根据验收或公榜调整。

## 6. 低分机制与实际失败案例

### 6.1 候选缺真值与候选内排序应分别诊断

未知验收扩展质量池仅覆盖 **106/994 = 10.66%**，固定路由实际可用池覆盖 **101/994 = 10.16%**。原始GAN在已覆盖子集的候选内MRR为0.21135，说明缺库和候选内排序同时存在。该未知代理任务的覆盖上限不是隐藏公榜的覆盖上限。

历史PubChemLite扩库把独立队列召回8.25%提高到12.00%，但旧已覆盖165例的候选内MRR由0.238749降到0.212793，抵消约45%的新增覆盖收益。扩库需要同时报告新覆盖贡献与原覆盖损失，而不是只看目录条目数。

### 6.2 错误保护及融合阻断正确预测

未知验收367题被保护，历史首位全部错误。这是移除同身份参考的严格未知任务，不等于隐藏测试37%的题都存在相同问题。路由后Top1为0，而GAN原始排序有12/994题Top1；固定旧首位策略本身限制了神经纠错。

| 真实代理验收案例 | 实际现象 | 机制判断 |
|---|---|---|
| `FQNCLVJEQCJWSU`，unknown | 相似度0.917；监督与GAN原始均第1，化学扩展第10；保护路由真值缺失Top25 | 真值已在扩展池，错误保护仅保留旧候选，阻断正确神经结果 |
| `CJGRGYBLAHPYOM`，unknown | 相似度0.498；监督原始第2、GAN第1；两者路由后缺失Top25 | 融合及固定旧首位压回错误结果，不能只优化指纹预测 |
| `CZIOOOMHRYWTQF`，known | 历史第7；监督路由第2、GAN路由第3；GAN原始缺失Top25 | 同池下GAN退化；真值在池，不是缺库 |
| `AAKGQCRLAXUVQW`，unknown | 590个原候选加入32个图，共622，仍无真结构 | 合法新图数量不能替代精确覆盖 |
| `ABLMUCSYDQOWAQ`，unknown | 656个原候选加入32个图，共688，仍无真结构 | 局部编辑搜索没有到达目标 |
| `ACHUYSGABSEHJM`，unknown | 池316，无真结构；相似度0.761被保护，无图生成 | 已见骨架不保证新身份识别，保护也挡住后续探索 |

这些身份来自独立代理验收，不是已知隐藏榜单逐题真标签。

### 6.3 化学证据覆盖不足

未知994题仅18题规则触发（1.81%），已知880题仅17题（1.93%）。V2已经对包括保护题在内的所有查询抽取证据，下一轮不能把“覆盖保护题抽取”误列为V2尚未实现的功能；问题是证据能否影响保护决策和最终排序。

`CJGRGYBLAHPYOM`真结构支持己糖规则，两张谱都有162质量差匹配，但加合物为Na/NH4，当前规则门控均不接受。它说明适用范围审计很必要，并不证明所有Na/NH4谱都应无条件接受该规则。扩展需有原始文献或可追溯词典支持，测量误匹配。

诊断峰不是官能团的唯一证据：质量差可能来自其他碎裂路径。缺失峰也不能直接否决结构。规则应用应保持软证据，并区分质量匹配、模式/加合物资格、SMARTS支持、排序变化和最终命中。

### 6.4 规范身份与重复候选

原始InChIKey14与官方互变异构体规范身份不完全一致。旧案例中等价结构曾重复占位；V2统一了规范身份，并在未知验收记录去掉1,478个重复槽位。下一轮需保留这项改进，避免缓存优化或新目录导入退回原始键去重。

## 7. 过拟合、潜变量与外推能力

### 7.1 有过拟合迹象，但不足以解释全部退化

| 模型 | 第6轮train probe BCE | 第6轮dev BCE | 第12轮train probe BCE | 第12轮dev BCE |
|---|---:|---:|---:|---:|
| 监督 | 0.177270 | 0.189698 | 0.163457 | 0.193710 |
| GAN | 0.192009 | 0.203687 | 0.182657 | 0.212360 |

训练probe继续改善、开发损失恶化，是后期过拟合或目标不一致的迹象。实际可见权重选第6轮，不能把部署失败解释为“使用最后一轮”。BCE逐位衡量指纹，最终评测按候选排序，损失下降不保证MRR上升。

D真实样本在0.5阈值下准确率0，不能单独判断判别器坏了。当前负项总权重为正项两倍，real软标签0.9，恒定无区分预测的最优概率约0.3；它也会产生real准确率0。恒定最优总loss约0.9163，实际末轮约0.8175。需要校准、区分能力和最终排名对照，不能用单个阈值准确率代替。

### 7.2 噪声利用弱，未证明多样结构生成

第6轮GAN不同噪声样本相对首样本的阈值指纹平均差异约 **0.70位 / 2048位**。这支持潜变量利用较弱，不足以单独断言完全模式崩塌。8个噪声样本不是8个分子结构，指纹合法性、多样性和精确结构恢复需分别衡量。

### 7.3 有限图编辑没有证明库外精确恢复

| 队列 | 按题去重图数 | 有新图的查询数 | 新图精确真值覆盖 |
|---|---:|---:|---:|
| 未知验收 | 16,807 | 545 | 0 |
| 已知验收 | 3,872 | 122 | 0 |

未知GAN路由答案仍使用1,816个生成图槽位，已知使用546个槽位：图确实参与排名，却未解决缺失真值。全部队列合计36,676只是按题求和，不是全球唯一新分子，也未证明PubChem外新颖性。

未知集新骨架524题的路由MRR为监督0.012719、GAN0.013125，路由候选覆盖8.59%。这是分层观察，不能据此宣称完成严格骨架外推验收。更强生成模型应先通过结构编码—解码精确重建，再测目录删真值的精确新增Recall@25。

## 8. 为什么运行耗时数小时

正式可见运行用时 **20,252.3秒，约5小时37分钟**，但两臂GPU训练合计约180秒。数据准备约3,730秒，其余主要是参考加载、串行RDKit规范化、图编辑和开发/未知/已知研究验收。

此外，权重重新加载后默认在CPU预测。T4 x2不会自动让这条链路使用两张卡，选更强GPU也无法直接解决串行化学处理。当前两个神经臂已共享候选/图编辑池，不能把这项已实现共享再宣传为新两倍提速。

隐藏评分重复执行完整研究Notebook，才会再次训练、准备并验收。下一次比赛Notebook应只加载已审核权重、预处理与索引，对实际挂载的test做推理。不能固定400行，也不能上传可见CSV充当隐藏预测。

固定权重入口的等价对象是相同权重的原Ranker，而不是随隐藏test重新排除身份、重新训练的V2全过程。缓存需记录RDKit版本、规范化配置、指纹定义、规则SHA和输入哈希；历史analog指纹与神经规范指纹语义不同，不应混用。
